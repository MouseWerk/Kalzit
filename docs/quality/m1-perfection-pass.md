# M1 perfection pass: record

The perfection pass (AICodeGuidelines `quality/perfection-pass.md`, with `security.md`,
`performance.md` and `bug-classes.md`) reviewed `main` at `c3c564d` for closing M1. It found
0 critical, 3 high, 17 medium and about 35 low findings, ranked in 22 numbered defects plus the
lows listed under each checklist item. This file records what became of every finding: fixed (with
the pull request), already fixed by a later change, or not fixed for M1 with the reason.

Status words: **fixed** (in the PR named), **already fixed** (by an earlier PR, verified against
`main`), **won't fix** (for M1, with the reason).
