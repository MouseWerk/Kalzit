# Kalzit 0.8.1

0.8.1 is the first release of M8. Graph panels get a working canvas (drag and pin, info cards,
edge details, context menus, lasso, search, minimap, undo), style rules with icons, seven layouts
and export as SVG, PDF and CSV; graph algorithms and paths run as steps on the server, while
their step catalog follows in 0.8.2. Most of the release is the work that brings Kalzit level
with what Grafana users expect: default data sources and Grafana addresses, a step catalog with
new table steps, axes, legend and tooltip options, query options and a table footer, "All",
data source variables, ad hoc filters and switches, the XY chart, Trend and Map panels, a Logs
view in Explore and a much closer Grafana import. Around it come Kalzit's own icons, four more
themes, the handbook inside the app, calmer sign-in pages and mails, quiet scrollbars, the M6
follow-ups (re-sign-in before the first second factor, trash retention, plugin folder) and many
fixes in edit mode and charts.

## Improved

- Graph panels: drag a node to move it; a dragged node stays pinned where you dropped it. While
  viewing, your pinned nodes, their places and what you hid are kept for you and are back after a
  reload; in the panel editor, pinned nodes and their places are saved with the panel for everyone.
  "Release all" and "Back to the panel's state" undo them.
- Graph panels: an info card shows a node's or an edge's caption, labels and up to four properties
  after the pointer rests on it, or with I for the focused element. The panel editor chooses the
  properties per label.
- Graph panels: click an edge to select it and open its own detail sheet, with its ends, its typed
  properties and the other edges between the same two nodes.
- Graph panels: context menus for a node, an edge, the selection and the empty canvas (right click,
  Shift+F10 or the menu key).
- Graph panels: select with a rectangle or a lasso, invert the selection, hide nodes and edges and
  show them again; the line above the graph says how much is visible. Search on the canvas in
  captions, properties and edges, and jump through the hits.
- Graph panels: a minimap, and Undo and Redo for changes of the view (moving, pinning, hiding,
  explorer steps, groups) with a history of the last 50 steps.
- Graph panels: the canvas tools (pointer, rectangle, lasso, search, undo, redo and zoom) lie on the
  canvas; every new action has a key, listed under "Graph" in the keyboard help (?).
- Graph panels: the table view lists what you hid, pins and releases nodes per row, selects edges
  and filters its rows with a search.
- Graph panels get style rules: under **Style** in the panel editor and in the panel head, rules set
  color, size, shape, icon, frame, label and badge of nodes, and color, width, line style, label and
  arrow of edges, always, on a condition or per unique value of a property. The lower rule wins,
  each rule reads as a sentence with its matches, and the legend names every rule. **Take over rules
  from another panel** copies the rules of another panel on the dashboard, and node and edge tables
  made from a graph show the same rules as a colored dot, icon, badge and label.
- About 360 icons for graph nodes, from Lucide (ISC), listed in the third-party notices.
- Graph panels: the layout is now a menu with Forces, Hierarchy, Radial, Circular, Grid, Coordinates
  and Timeline, each with a short description and the reason when it cannot apply to a result.
  Radial arranges rings around the selected nodes, Coordinates uses two number properties or a
  `point` property, and Timeline places nodes by a time property in lanes.
- Graph layouts are computed in the background with progress and Cancel and give the same result
  every time; "Arrange again" (Shift+L) is offered for Forces and Radial, where the result can come
  out differently. A hierarchy handles up to 10,000 drawn nodes, and larger results offer "Close
  groups". Layouts draw quiet guide lines behind the graph (rings, axes, lanes) and show nodes
  without a value or time in a strip with their number.
- Graph panels have an **Export** menu with the image formats **PNG**, **SVG** and **PDF**, and the
  data formats **GraphML**, **JSON** and two new **CSV** files for nodes and edges. SVG images keep
  every label as text and stay sharp at any size; PDF images are a single small page of vector
  shapes. The image dialog lets you choose the visible part, the whole graph or the selection, the
  background, the legend and the title, data source and time range.
- GraphML files now carry where each node is drawn, and the data formats can export only the visible
  nodes. The data dialog counts only the nodes of the panel's query and names those loaded with the
  explorer apart, since the file does not hold them.
- Everyone who may see a panel can save it as an image. GraphML, JSON and CSV still need the right
  to export data, and the menu says so when you do not have it.
- Graph results can run algorithm steps: centrality (PageRank, betweenness, closeness, eigenvector,
  harmonic), communities and components, k-core, triangles and clustering, similarity (Jaccard,
  overlap, cosine, nearest neighbours), suggested edges, shortest, weighted, all and k shortest
  paths, reachable nodes, bridges, articulation points, cycles, merging nodes and aggregating along
  neighbours or paths. The steps work on exactly the query result and never write to the data
  source. The step catalog in Explore and the panel editor follows in 0.8.2.
- Algorithm steps compute in Neo4j with Graph Data Science or in Memgraph with MAGE where they can,
  otherwise on the Kalzit server, which also takes over automatically when the database cannot. Each
  step says where it ran and why, and sums up its result in one sentence. A step the database's
  library could not finish in time runs on the Kalzit server for a while for results of that size
  and larger, instead of waiting for the library again.
- Suggested edges stay apart from the data: they are not counted, not read by later steps and not
  exported. "Degree" can count only some edge types and sum an edge weight.
- Settings > Data sources and targets has limits for graph steps: time, nodes, memory, steps at
  once, paths and cycles, top k and suggestions. Organizations can only lower them.
- New panel **XY chart**: two number fields against each other, a point per row, with a series per
  value of a field, size and colour by a field, and points, lines or both. Above 12,000 points it
  draws an even sample, says so and offers a density view; drag a rectangle to zoom in. See
  [Panels](../guide/panels.md#xy-chart).
- New panel **Trend**: a time series over an ascending number field instead of time. It never sorts
  or groups by itself; when the X values do not fit, it says where and, in the panel editor, offers
  the step that makes them fit or the XY chart.
- New panel **Map**: places from rows and documents as points, placed by latitude and longitude, a
  point field, a geohash or a country code, and countries filled by a value as areas, in up to four
  layers. The map draws outlines of countries and regions that ship with Kalzit, so it works without
  any network and never asks a map service. Near points are bundled, rows without a place are
  counted and listed with their reason, and a table view shows the same places. Graph results keep
  showing their nodes and edges on the map.
- Time series, bar charts and histograms have a new option group "Axes": placement (auto, left,
  right, off), a label, a fixed width, grid lines, the axis color and line, a linear, logarithmic
  (base 2 or 10) or "log around zero" scale, zero in the middle and soft limits. A field with a
  second unit gets the right axis automatically, and an override can put any field there. A log
  scale says how many points it leaves out (values of zero or below) instead of dropping them
  silently.
- The legend shows any of 19 values per series, picked in four groups (frequent, over time,
  distribution, count) with a search: among them total, count, first, difference, change in %,
  range, standard deviation, variance, median and any percentile. At most six per panel; the list
  shows the first two, the table all of them and sorts by a click on a column. Legends in list mode
  that had more than two values now show the first two; switch to the table for all. The legend
  takes a width beside the chart and a limit of series, with "show all" for the rest.
- The time series tooltip sorts its series by value, can hide series at zero (and says how many) and
  takes a largest width and height; beyond that it scrolls with the time kept at the top.
- The panel editor's group "Panel" has the description and the transparent background. The
  description shows behind the info sign in the panel header, with links, emphasis and dashboard
  variables filled in.
- Tables can show a footer: one calculation per column, such as the total, the mean, the count ("4
  of 2,000 rows") or the 95th percentile, over all rows of the query or only the filtered ones. It
  stays in place while you scroll and always says what it calculates over.
- Panels have query options above their queries: the maximum data points, the smallest interval
  (with the interval that results), their own time range and time shift (moved here), a cache time
  and hiding the time note in the header. The server applies the points, the interval and the cache
  time to the saved panel everywhere it runs.
- Charts in small panels stay readable: a legend below the drawing leaves the chart a least height
  and shows names only in narrow panels, a short wide panel keeps its legend beside the chart, pie
  labels outside the circle give way before the circle shrinks to a dot, and long value axis labels
  drop their unit or are shortened instead of taking half the width.
- Bar chart category names turn at an angle when they do not fit side by side, so every name shows,
  and names at the panel's edges are no longer cut off. Gauges fill the space of their panel, also
  in short wide panels, and several values in one stat panel stand side by side in a short panel
  instead of the last one being cut off.
- Axis ticks use only the decimals they need ("€1,500" instead of "€1,500.00"); values keep the
  decimals set for the field.
- Annotations are thin dashed lines and light bands in their own color over the plot only, with a
  small marker on the time axis, so dense charts stay readable.
- "Load more documents" now also works in a saved analysis opened to view and run, and in the
  preview of the panel editor. It appends the next documents when the source has more, as on a
  dashboard; running again starts from the first page.
- "Add step" opens a step catalog: search by name, description or a common term (rename, merge,
  top), the steps you added last, the table steps in six groups and a preview of each step on the
  first rows of your own result. Steps that do not fit your data yet are dimmed and say why.
- New table steps: Arrange and rename fields, Filter fields by name, Convert type, Filter rows,
  Limit, Stack tables, Series to rows, Reduce and **Sort** (up to five fields, ascending or
  descending). They run in the browser and in exports alike. The step "Trend" is now called **Trend
  line**.
- Patterns in Filter fields by name and in the "matches" condition read the first 150 characters and
  refuse forms that could freeze a viewer's browser, with the reason shown while you type.
- Variables with fixed values or values from a query can offer "All". It stands first in the list, a
  dashboard can open with it, and it sends every value as a list, or one custom value for "All"
  (such as `.*`), always as a parameter. Every multi-value variable can also **Start with every
  value picked**.
- Variables with values from a query have a regex filter (named groups `text` and `value` split the
  shown name and the value), a sort order, a choice between reading the values on load or on every
  new time range, and fixed extra values. A preview in the dashboard settings shows the values as
  the filter bar will.
- Panels and links that use a variable from a query at "All" wait until its values are loaded, and
  show why when its query fails, instead of running first with an empty list.
- Share links, reports and AI answers keep "All" and read the variable's values each time they run,
  with the rights of the person they belong to, instead of a list frozen when they were made.
- Variables can allow typed values outside their list. Choices in the filter bar keep a minimum
  width, so picking a shorter value no longer moves the variables after it.
- Dashboards can have a data source variable: panels that use it switch to another source of the
  same kind from the filter bar, which lists the sources you may query. Everyone sees the saved
  default; picking another source needs your own right to query it.
- Dashboards can have ad hoc filters: field, comparison and value, built into every query of their
  data source by the server. They work with Prometheus, Loki, Elasticsearch and OpenSearch, and with
  SQL queries that write `$__filter`. Values always go in as parameters or escaped text. In the
  filter bar they show as chips: add one with field, comparison and value, change any part with a
  click on it, or remove it; the comparisons offered are those the data source can apply. A panel
  says when the filters do not narrow it because another data source is picked, and public pages
  show only the number of filters.
- Dashboards can have a switch variable that sends one of two fixed values; it shows as a switch in
  the filter bar.
- The dashboard settings have forms for data source variables, ad hoc filters and switches, and
  Dashboard settings > Variables has a "Dependencies" tab: a drawing and a table of which variable
  needs which, where each is used, and what is unused, in a cycle or missing.
- Query variables on Prometheus sources offer four helpers instead of a typed query: label values,
  label names, metrics and query result. The query behind the helper stays visible.
- Explore has a **Logs** view for log lines from Loki, Elasticsearch, OpenSearch and other document
  sources: time, level as a dot and a word, and the line, with the volume by level over the whole
  range above them (for Loki counted by a query of its own, otherwise from the loaded lines, as it
  says). Wrap, prettify JSON, order and four ways of merging duplicates change only the view; a line
  opens with its labels and fields, and **Filter for** and **Filter out** add the filter visibly to
  the query. The view reads the documents unchanged; under **Fields** you see and change which
  fields it reads ([Explore](../guide/explore.md#logs)).
- Loki log queries load 1,000 lines unless you set another limit, at most 5,000.
- SQL queries know the time macros Grafana users know: `$__time`, `$__timeEpoch`, `$__timeGroup` and
  `$__timeGroupAlias` (buckets such as `1h`, `$__interval` or an interval variable, with `NULL`,
  `previous` or a number to fill empty buckets), and the Unix epoch macros `$__unixEpochFilter`,
  `$__unixEpochNanoFilter`, `$__unixEpochFrom`, `$__unixEpochTo`, `$__unixEpochNanoFrom`,
  `$__unixEpochNanoTo`, `$__unixEpochGroup` and `$__unixEpochGroupAlias`, on every SQL source. The
  Macros section under the SQL editor and the completion list them with a short description each.
- When a data source cannot read a value of a query, the error now says so in plain words and points
  at the variables and casts; the technical text stays under the details.
- Choose a default data source for your organization: **Make default** in a source's menu in the
  list, or **Default data source** in the form. Explore and new panels start with it when no source
  is chosen, and a Grafana import proposes it for Grafana's default source.
- Grafana addresses work in Kalzit: `/datasources` and `/connections/datasources` open the data
  sources, `/connections/datasources/new` adds one, and `/d/<uid>` opens a dashboard imported from
  Grafana (or the dashboards list when the uid is unknown).
- Import from Grafana carries over much more of a panel: units become Kalzit's units (a euro value
  reads as euros, not "40 k currencyEUR"), field overrides by name and pattern, value mappings with
  their colours, series names from Prometheus and Loki legend formats, the time series' graph style,
  stacking, threshold display, legend and tooltip, table column names, cell displays and footers,
  heatmap bucket options and the query options (data points, interval, cache time). The import
  report lists only what has no counterpart.
- The Grafana import keeps axis placement, label, width, grid lines, scale and soft limits, legend
  values (including total) and legend width, tooltip sort, hidden zeros and size; legend values
  without a counterpart are named in the report.
- The Grafana import takes over XY charts and trend panels, and geomap panels become maps: marker
  layers keep their place, size and query, and the report names what is not taken over (base map
  images, heatmap, route and GeoJSON layers, a fixed view).
- The Grafana import takes over organize, filter fields by name, filter data by values, limit,
  convert field type, reduce, merge and series to rows as steps and reports what it leaves out.
- Variables that stand on "All" in Grafana start with every value picked. The import takes over
  "All" with its custom value, typed values, and the regex, sort order and refresh of query
  variables; `label_values(...)`, `label_names(...)`, `metrics(...)` and `query_result(...)` on
  Prometheus sources; data source variables, ad hoc filters, and custom variables with two values
  such as `true, false` as switches. The report says what changed.
- Imported Grafana dashboards that use the SQL time macros above run unchanged, and the import no
  longer warns about them.
- The Dashboards page has a side column with All dashboards, Favorites and Recently opened, the
  folder tree with a count per folder, and Playlists, Library panels and Trash below it. One Import
  menu holds Import from Grafana and Import… next to New dashboard.
- Dashboards: search finds dashboards by title, tag or folder name; filter by tag and sort by last
  change, name or last opened. The list now starts with the most recently changed dashboards and
  shows a star to mark favorites, the folder path, tags and when and by whom a dashboard was last
  changed.
- Dashboards: switch between List and Cards; cards show a sketch of each dashboard's panel layout,
  and the choice is remembered. All dashboards shows the four dashboards you opened last above the
  list.
- Edit mode on dashboards does what you click: Edit, Duplicate and the menu in a panel's header
  react to the first click, dragging starts only once the pointer moves, and selecting a panel no
  longer narrows the dashboard or moves panels under the pointer.
- Opening a panel in the editor takes one step: double-click its content, or press E while the
  pointer is over it. Opening a panel's menu selects that panel.
- Saving keeps you in edit mode, and finishing with unsaved changes offers Save next to Discard.
  Saving shows what changed, in words (with which parts of a panel) or line by line as JSON, and
  offers "Save as copy". When someone else saved in the meantime, the conflict dialog can also save
  your changes as a copy, so both versions stay.
- The panel editor shows the dashboard's variables above the preview; a value chosen there re-runs
  the preview and applies to the dashboard too.
- The column on the right of a dashboard now reaches down to just above the window's lower edge, so
  it shows more of its buttons and lists; in a low window it scrolls inside itself.
- Kalzit has its own icons: every icon in the app is redrawn in one language taken from the Kalzit
  mark, with octagons instead of circles, corners cut at an angle and rhombi for nodes and knobs.
  Icons with a surface (dashboards, data sources, the bell, people, files) carry one lightly tinted
  facet. The high contrast theme and the Windows contrast modes show the plain line only.
- Icons move a little: navigation and toolbar icons play a short motion on hover and keyboard focus,
  and give way when pressed. A successful connection test, a copy and a new favorite show their
  check or star once; a rule that starts firing rings the Alerting bell once. While a test, a check
  or a dashboard refresh runs, its refresh icon turns. With reduced motion turned on in the system,
  every icon stands still.
- Four more themes: Paper (warm off-white) and Calcite (cool blue-grey) as light variants, Graphite
  (almost black, for OLED screens) and Night (deep blue-grey) as dark variants. In Settings >
  Profile and language you pick the mode (System, Light, Dark, High contrast) and one light and one
  dark variant; System switches between the two with your device. The account menu, the command
  palette and the sign-in pages offer the mode; before sign-in the server's default variants apply.
  Nothing changes until you choose.
- Settings > Appearance and brand: besides the default mode, admins set the default light and dark
  variant for everyone without a choice of their own.
- The accent color "Graphite" is now called "Gray"; a stored choice stays as it is. A new custom
  accent color is checked against the surfaces of every variant, so a color that passes stays
  readable in each of them. A custom color chosen before keeps showing.
- Scrollbars are thin and quiet everywhere (pages, panels, tables, menus, editors and dialogs) and
  fit every theme in light and dark. They show stronger while the pointer is over the area that
  scrolls.
- On wider screens only the page area next to the sidebar scrolls: the sidebar, the top bar and the
  dashboard toolbar stay in place, and the page no longer shifts sideways when its content grows
  longer than the window.
- The sidebar slides smoothly when you collapse it to the icon rail or open it again. Collapsed, it
  slides out over the page while you rest the pointer on it. Drag its edge to set its width; drag it
  narrow to collapse it, or all the way to the window's edge to hide it. Pinned dashboards stay in
  the collapsed sidebar as letter tiles, and groups of sub-pages have a clear heading.
- Focus mode (Ctrl+Shift+B, or "Focus mode" in the command palette) hides the sidebar completely;
  rest the pointer on the window's left edge to bring it in.
- Reloading a page shows the Kalzit mark with a quiet loading bar in your theme right away, instead
  of an empty screen until the page appears. With reduced motion turned on, the bar stands still.
- The keyboard shortcuts help (press ? anywhere) is new: a search over meanings and key names, a
  list of areas, and the shortcuts that apply where you are shown first. It lists every shortcut of
  the app, also those of Explore, charts, graphs, traces, the analyses list, notification policies,
  Ask and the AI draft. ? opens and closes it, Esc clears the search first.
- Keys are named as on your keyboard in every language and on every platform: Strg, Umschalt,
  Eingabe, Leertaste and Entf in German; ⌃ ⌥ ⇧ ⌘ in the macOS order without "+", and ⌫ for deleting
  on a Mac. Screen readers hear shortcuts by their names ("Control plus K").
- Kalzit's guide is now inside the app: **Help > Handbook** opens the handbook with every page of
  the guide in English and German, the operator pages (offline updates, several servers, winget) and
  the glossary. It is part of the program, so it works without internet and always matches the
  installed version.
- The handbook follows the language of the interface; a page without a German version shows the
  English one and says so. "Read in English" and "Auf Deutsch lesen" switch a single page.
- **Search the handbook** finds sections in both languages, with the sentence each word was found
  in, word forms and umlauts included. The search runs in your browser; what you type is never sent
  anywhere. **/** searches it, **[** and **]** (or **K** and **J**) turn to the previous and next
  page.
- Every handbook page has contents, "On this page", previous and next, links to each section, code
  blocks with **Copy**, the guide's screenshots and notes and warnings. Some pages open the screen
  they describe, such as **Open Administration > Backups**, for people who may open it.
- The guide links of the app lead into the handbook instead of GitHub. **Help > Kalzit on GitHub**
  stays as the one link outside; **Help > Documentation** is gone. Server admins can turn the
  handbook off under Settings > Appearance and brand with **Show the handbook**; guide links then
  open GitHub.
- Every page before the app (sign in, second factor, setup, create account, invitation, reset
  password, confirm email) has the same calm layout: one narrow column without a card, one heading
  size, at most one message, one main action and the side paths below. Error pages stand in the same
  frame.
- Sign-in providers stand above the password form, the first one as the main action; the password
  form is folded while providers are there.
- Results such as "Check your inbox", "Your password is changed" or an expired invitation are whole
  pages with one sentence and one action, instead of small tinted notices.
- Waiting after failed attempts is called a pause and says how long it lasts; "locked" now only
  means an account locked by an admin. The checkbox under the password is now "Shared or borrowed
  computer". An invitation shows who invited you, the role, the team and how long it is valid.
- People who sign in through an OpenID Connect provider and set up their first second factor now
  sign in at the provider again first ("Sign in at ..."); the provider asks for the sign-in even if
  the browser is still signed in there.
- Three wrong passwords in a row in one session are recorded in the audit log once ("Password
  entered wrongly several times in a session"), and the person gets a mail about it when the server
  can send mail.
- Invitations, password links, address confirmations, sign-up, second-factor and break-glass
  notices, the LDAP sync notice and the test mail now share one calm design: a header with the
  product name, one heading, the facts as a short list, at most one button with the link written out
  below it, a box with how long a link works and what to do if it was not you, and a short footer.
  Mails use your product name and accent color, come in a light and a dark version, and load nothing
  from the network; the plain-text part is wrapped for reading and never breaks a link.
- Settings > Email has a new switch "Mark in the mail header": it shows the mark or your own logo as
  an image carried inside the mail, or the name alone as text.
- Settings > Email offers "No encryption" next to STARTTLS and TLS, for example for an internal mail
  relay on port 25. It is plain SMTP to any host in your network and never switches to STARTTLS; a
  user and password stay possible. The page warns calmly that mails, the server address and, with a
  user, the password travel unencrypted, so use it only for a trusted relay in your own network.
  `security = "none"` in `kalzit.toml` or `KALZIT_SMTP_SECURITY` works the same way and is no longer
  limited to a relay on the same computer.
- The Administration page lists its sections as calm grouped lists (People and access, Sharing and
  operations, Accounts, Operations, Monitoring) with an icon and one short line each, instead of a
  wide row of cards; an available update shows right on its row. It shows how many members, teams,
  roles and service accounts the organization has, and for server administrators how many accounts
  and organizations the server has.
- Settings > Storage and retention: "Data source trash (days)" sets how long deleted data sources
  stay in the trash (default 30). The trash shows the date each source is deleted for good. Fewer
  days apply only to data sources deleted afterwards: nothing already in the trash is deleted
  sooner. More days also extend the sources already in the trash.
- The plugin folder can live outside the data folder (`paths.plugins_dir` in `kalzit.toml` or
  `KALZIT_PATHS_PLUGINS_DIR`); an existing folder moves there at the next start, and Settings >
  Storage and retention shows the folder in use. The folder must be missing, empty or Kalzit's own;
  a general folder with other files in it is refused (`desktop.ini`, `Thumbs.db` and `.DS_Store` do
  not count).
- Plugins: the example data source "CSV and JSON over HTTP" is now released for Linux on arm64 too
  (for example AWS Graviton, Ampere or a Raspberry Pi), signed like the x64 and Windows builds.
- Security: the SAML libraries are updated together (gamlastan 0.10, bergshamra-dsig 0.11).

## Fixed

- Dashboards: the time range and variables bar and the column on the right no longer slide up a few
  pixels when you start scrolling; they stay exactly in place from the first moment.
- Dashboards: on a laptop or a narrow window the list no longer reaches past the window and names no
  longer break letter by letter; the folders move above the list when there is no room beside it.
- In narrow panels the menu button no longer falls out of the header: where there is no room, the
  header hides Edit, Duplicate and the size, and the menu keeps Edit and Duplicate.
- In edit mode a click on a panel's chart or table selects the panel, and a double click there opens
  it in the editor. The selected panel's size badge no longer covers its content, and a resized or
  moved panel takes its new place at once.
- Back from the panel editor, only the edited panel loads again; the others keep their data.
- Dropping a dragged panel in edit mode no longer makes the page stutter for a moment; the dragged
  panel is selected with the drop.
- A pie chart could show its donut pushed out of the panel and a cut-off legend on first load until
  it was drawn again.
- A dashboard interval variable used in a PostgreSQL query, such as `date_bin($bucket::interval,
  created_at, timestamptz '2000-01-01')`, failed with "insufficient data left in message". Text
  variables now work wherever PostgreSQL expects another type, such as an interval or an integer
  column.
- A unit Kalzit does not know (stored by an earlier import) is no longer printed after values; the
  panel editor names it as an unknown unit instead of showing "From the data source".
- Dashboards imported from Grafana before this release get their units taken over at the next start
  of the server, once, as a new version of each dashboard with an entry in the audit log; the
  previous version stays in the history and units Kalzit cannot map stay as they were. Dashboards
  managed by provisioning files and dashboards in the trash are left alone.
- A data source that passed **Test connection** in the form no longer shows "Not tested" in the list
  right after saving.
- The alert rules list no longer scrolls sideways in a narrow window when a silence ends on another
  day. Under a rule's state, the end of its silence now shows the time when it ends today and only
  the day when it ends on another day (with the year if that is another year). Screen readers still
  read out the full date and time.
- The sidebar no longer jumps after a page load: Alerting, Reports and Pinned are in place from the
  start instead of popping in and pushing the other entries down.
- Kalzit's own PostgreSQL database is now refused as a plugin, mail or outbound proxy target however
  its address is written: several hosts in one URL, `host`, `hostaddr` and `port` parameters (also
  percent-encoded), key=value strings, IPv6 addresses, unix-socket directories (a socket database
  counts as on this machine) and the `PGHOST`, `PGHOSTADDR` and `PGPORT` defaults. While one of its
  host names cannot be resolved, its port is refused on every address.
- Redo in the query editors works with both Ctrl+Y and Ctrl+Shift+Z on every platform (⇧⌘Z and ⌘Y on
  a Mac), and shortcut hints in Explore, the graph and chart annotations show Cmd on a Mac instead
  of Ctrl.
- Holding down Ctrl+K, Ctrl+B or ? no longer makes the palette, sidebar or help flicker.
- On the analyses list, / always goes to the list's search, however the page was opened.
- On keyboards with a different letter order (German QWERTZ, French AZERTY) shortcuts follow the
  letter on the key: Ctrl+Y is redo, not undo, and Q no longer adds an annotation.
- The keyboard help also lists moving sign-in providers (Alt+Up and Down) and stopping an AI answer
  with Esc.

## Checklist for Windows (manual)

- Open the sidebar, a dashboard toolbar and Administration in the light, dark and high contrast
  theme: icons are sharp at 100 %, 125 % and 150 % display scaling, and the tinted facets are gone
  in high contrast and with a Windows contrast theme.
- Settings > Profile and language: choose Paper and Night, set the mode to System, switch Windows
  between light and dark: the page follows without a reload and without a flash after a reload.
- Check the scrollbars in Light, Paper, Calcite, Dark, Graphite, Night and High contrast.
- Open a long dashboard and a long settings page: only the area next to the sidebar scrolls, the top
  bar stays, and nothing moves sideways while content loads.
- Scroll with the mouse wheel, PageDown, Space, Home and End right after opening a page; go to
  another page and back with the browser's Back button: the page returns to where it was.
- Settings > Data sources and targets shows the graph step limits; changing one saves and can be
  undone.
- Open a dashboard, choose Edit, click a panel and then Edit in its header with the mouse: the panel
  editor opens. Selecting panels does not change the width of the others, also with a visible page
  scrollbar.
- On a PostgreSQL source, add an interval variable `bucket` with `1h,6h,1d` to a dashboard and run
  `SELECT date_bin($bucket::interval, created_at, timestamptz '2000-01-01') AS t, count(*) FROM ...
  GROUP BY 1 ORDER BY 1`: the panel shows one row per bucket for each choice of `bucket`.
- Run `SELECT $__timeGroupAlias(created_at, $bucket, 0), count(*) FROM ... WHERE
  $__timeFilter(created_at) GROUP BY 1 ORDER BY 1`: empty buckets show 0, and the Macros section
  under the editor lists the new macros in German and English.
- Explore with a Loki source: run `{app="..."}`, check that **Logs** opens with level words and the
  volume, open a line and use **Filter for**; the query shows `| label = "value"` and runs again.
- In the panel editor of a time series, set the scale to "Logarithmic" on data with zeros: the chart
  draws with ticks at 1, 10, 100, ... and names the left-out points below it.
- Pick "Total" and a percentile as legend values, switch the legend to a table and sort by a column;
  check the chips, the picker and the table at 100 % and 150 % display scaling in the light, dark
  and high contrast themes.
- In Explore on a SQLite source, open "Add step" with the interface in German ("Schritt
  hinzufügen"), search "umbenennen" and "top", walk the list with the arrow keys and add a step with
  Enter; the preview on the right shows your rows.
- Add an ad hoc filter to a dashboard with a SQLite panel that writes `$__filter`, change its value
  through the chip, remove it; the panel follows each step.
- Open Dashboard settings > Variables > Dependencies and check the drawing and the table.
- Create a query variable on a Prometheus source with "Label values" and check the preview.
- Import a Grafana dashboard with a `label_values(...)` variable and an ad hoc filter.
- Edit a panel, open "Query options", set 100 data points and a smallest interval of 5m, apply and
  save: the save dialog lists the change, "As JSON" shows it, and the panel stays in edit mode after
  saving.
- Turn on a table's footer with "All number columns: Total" and a column filter, switch "Calculates
  over" to the filtered rows, and check the footer and the line under the table.
- Add a map panel to a dashboard with a query that returns `lat` and `lon` columns, and one with a
  country code column as an areas layer: the outlines show with the network cable unplugged, the
  points and areas match the data, and "without a place" lists rows with empty coordinates.
- Import a Grafana dashboard with a geomap panel: the panel becomes a map and the report names the
  base map.
- Settings > Email: choose "No encryption", enter an internal relay in your network with port 25 (or
  leave the port empty), send a test mail and save; the mail arrives, the test result shows no TLS
  version, and the warning under Encryption is shown (with a second sentence once a user is
  entered).
- Set `plugins_dir` under `[paths]` in `kalzit.toml` to a folder on the same drive, restart the
  service, and check that the installed plugins moved there and still run.
