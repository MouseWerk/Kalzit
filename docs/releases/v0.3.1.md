# Kalzit 0.3.1

## Improved

- Browsers you signed in with before are remembered for 90 days. While someone guesses your
  password from elsewhere, you still sign in from them; other browsers wait until the guessing
  has stopped for a while. A new password makes Kalzit forget them.
- Guessing a password stays slow, also when it is spread over many addresses.
- Preview, off unless a server admin turns it on: AI help in Explore and on panels (explain or
  draft a query, summarize a result) with providers set up under Verwaltung > KI, and data source
  plugins installed from a signed file. Both are still being built for 0.4.0; plugins can reach
  the network freely for now.

## Fixed

- Setup could no longer be completed after many wrong setup codes from other addresses: the
  right code now opens setup from an address that has not been guessing, while guessing stays
  slow.
- A flood of sign-in attempts from many addresses could reset the sign-in limits of others or
  keep everyone out; the limits now stay until their time is up, and addresses from other
  networks can still sign in.
- Many wrong passwords sent at the same moment can no longer get past the sign-in limits.
- A change of the system time no longer ends or stretches a sign-in wait.
- A graph step that Neo4j or Memgraph did not finish in its share of the query's time kept
  running in the database after Kalzit had moved on; it is now stopped.

## Checklist for Windows (manual)

- Setup on Windows: start a fresh server with `security.setup_max_failures = 5` in `kalzit.toml`.
  Enter a wrong setup code five times from one computer and check that a sixth try is refused
  with a wait. Then enter the right code from another computer and check that setup completes.
- Sign-in on Windows: sign in once in a browser and sign out. On another computer enter a wrong
  password until the page says to wait, and check that the right password is refused there too.
  Then check that the first browser still signs in with the right password.
- Graph steps on Windows: with a Neo4j source, run a Cypher query with a graph step in Explore and
  check that the result arrives as before.
