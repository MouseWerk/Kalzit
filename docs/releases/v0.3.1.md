# Kalzit 0.3.1

## Improved

- Wrong passwords from other addresses no longer lock you out of your account: you can still sign
  in from your own address while someone else is guessing. Guessing stays slow, also when it is
  spread over many addresses.

## Fixed

- Setup could no longer be completed after many wrong setup codes from other addresses: the
  right code now always opens setup from an address that has not been guessing, while guessing
  stays slow.
- A flood of sign-in attempts from many addresses could reset the sign-in limits of others; the
  limits now stay until their time is up.
- A graph step that Neo4j or Memgraph did not finish in its share of the query's time kept
  running in the database after Kalzit had moved on; it is now stopped.

## Checklist for Windows (manual)

- Setup on Windows: start a fresh server, enter a wrong setup code three times from one browser,
  then enter the right code from another computer and check that setup completes.
- Sign-in on Windows: enter a wrong password until the page says to wait, then sign in with the
  right password from another computer and check that it works.
- Graph steps on Windows: with a Neo4j source, run a Cypher query with a graph step in Explore and
  check that the result arrives as before.
