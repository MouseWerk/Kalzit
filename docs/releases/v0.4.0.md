# Kalzit 0.4.0

## Improved

- Data source plugins: server administrators install a plugin from its package file, approve the
  network targets it declares, and enable, disable, restart or remove it. Its kind then appears
  next to the built-in kinds, with the labels from its manifest.
- Every package is checked before anything in it runs: only the files its manifest lists, no
  links, a valid signature from a trusted key. Unsigned plugins only with an explicit switch, off
  by default; a broken signature is always refused.
- Administrators manage the publisher keys they trust. Removing a key stops the plugins signed
  with it, after a confirmation; publishers can hand a plugin over to a new key.
- Updates of a plugin stay with its key and never go back to an older version. An update that
  wants to reach new targets waits for approval while the installed version keeps running.
- Plugin processes start when they are first needed, are restarted with growing waits after a
  crash, and stop after repeated failures until an administrator restarts them. A crashing
  plugin fails only the queries of its own kind.
- Plugin processes run in a sandbox: on Windows with a restricted token in a job object, on Linux
  with Landlock, seccomp and namespaces where the system offers them. The plugin page lists which
  layers are active.
- Organization administrators can block an installed plugin for their organization.
- Installing, approving, enabling, removing, blocking and every change of trust are recorded in
  the audit log.

## Fixed

- Test connection and the schema of a data source whose kind is not available answer
  "kind not available" instead of an internal error.

## Checklist for Windows (manual)

- On a Windows service installation, install a signed data source plugin: add the publisher key,
  upload the package, approve and enable it; create a data source of its kind and run a query.
  Check in Task Manager that the plugin process runs under the service account and ends when the
  plugin is disabled and when the service stops.
- Upload the same package with one file changed and check that it is refused before anything
  runs.
