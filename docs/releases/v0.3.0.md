# Kalzit 0.3.0

## Improved

- Graph steps in Explore and in panels: count nodes per label and edges per type, the degree
  distribution, the top N nodes by degree, shared neighbours (such as customers who bought the
  same products) and "Turn into a table"; Neo4j and Memgraph run them in the database, and each
  step shows where it runs and how it changes the shape.

## Fixed

## Checklist for Windows (manual)

- Graph sources on Windows (the automated browser tests run Neo4j and Memgraph on Linux only): add
  a Neo4j source, run a Cypher query that returns nodes and relationships in Explore and check
  that the result shows as a **Network** with its node and edge count; switch to **Hierarchy** for
  a tree of relationships and to **Paths** for a `shortestPath` query and check the path reads as
  node, relationship, node. On a dashboard, lower a network panel's node limit below the result
  and check the note about the limit and **Show as table**; turn on explorer mode, load a node's
  neighbours, check that no more than the set number arrive and that **Undo** removes them; let a
  click on a node set a text variable and check that a panel using it follows. Repeat the Explore
  query against a Memgraph source.
- Graph steps on Windows: in Explore, run a Neo4j query that returns customers, purchases and
  products, add "Shared neighbours" and check "Runs in Neo4j (Cypher)" and the pairs in the
  preview; add "Group" after it; add the panel to a dashboard and check that a viewer sees the
  same table.
