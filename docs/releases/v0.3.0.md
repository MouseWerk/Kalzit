# Kalzit 0.3.0

## Improved

- Variables work across result shapes: a click on a document in the document explorer or card,
  or on a table row, sets a dashboard variable, as a click on a graph node already did, and Cypher
  and GSQL panels follow it.
- Query variables can take their values from graph nodes, relationships or document fields.

## Fixed

- A dashboard variable written into GSQL code as `$name` now says to declare a query parameter.

## Checklist for Windows (manual)

- On a dashboard with a MongoDB document explorer that sets a variable and a Neo4j panel that
  uses it, click a document and check that the Neo4j panel shows the matching data.
