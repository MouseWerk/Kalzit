# Kalzit 0.1.0

## Improved

- First start: set up Kalzit in the browser with the one-time setup code from the data directory,
  creating the first organization and its owner.
- Sign in with email and password; on your account page, change your name and password and end
  your sessions.
- Organizations with members, teams and the roles owner, admin, editor and viewer, plus custom
  roles made of individual permissions, managed in the administration.
- Server settings and organization settings in the administration, showing where each value comes
  from (environment, configuration file or saved in Kalzit).
- An audit log of sign-ins and changes, kept for a configurable number of days.
- Server administrators manage user accounts and organizations.
- Through the API: folders and dashboards with trash and version history, restricted folders,
  sharing with people, teams and roles, and read-only data sources for PostgreSQL, MySQL and
  MariaDB, SQL Server, SQLite and Prometheus with encrypted passwords.
- Without configuration, Kalzit keeps its data in a system folder: `%ProgramData%\Kalzit\data` on
  Windows and `/var/lib/kalzit` on Linux, never in the folder it was started from (for a Windows
  service, `C:\Windows\System32`). `paths.data_dir` in `kalzit.toml` or `KALZIT_PATHS_DATA_DIR`
  choose another place.
- Relative paths in `kalzit.toml` (data directory, certificate, key, SQLite database) are relative
  to the folder of the file, wherever Kalzit is started from.
- The data directory is created private: only the account Kalzit runs as and administrators can
  open it. Kalzit refuses to start when an existing data directory, or a file in it, is open to
  other accounts, and the message says how to fix it.
- Linux with systemd: run Kalzit as its own user with `StateDirectory=kalzit` and
  `StateDirectoryMode=0700` in the unit; without systemd, create the folder with
  `sudo install -d -o kalzit -m 0700 /var/lib/kalzit`.
- Windows: run the service as a virtual account (`NT SERVICE\Kalzit`) or as LocalSystem. Kalzit
  creates a missing `%ProgramData%\Kalzit` writable only by administrators; `kalzit.toml` and the
  folder are refused when other accounts could change them. If you ran Kalzit once as a normal
  user before installing the service, the service refuses the folder that user created and says
  how to fix it with `icacls`.
- Docker volumes and WSL drives (drvfs): the data directory must belong to the user Kalzit runs as,
  with mode 0700; otherwise Kalzit refuses to start (for drvfs, mount with `metadata` and set the
  owner and mode, or use a folder on the Linux file system).
- The built-in SQLite database lets reading go on while changes are saved. When it is briefly
  busy, the server says so and the browser tries again on its own.
- A SQLite database on a network drive is refused at start with a clear message; use PostgreSQL
  for shared storage or several Kalzit servers.
- The start log names the data directory and the database. The database address is shown with the
  password and all query values replaced by `***`, except harmless settings such as `sslmode`.
  When special characters in the password are not percent-encoded, Kalzit warns at start and shows
  only the scheme of the address, such as `postgres://***`.
- Backups: while Kalzit runs, use `VACUUM INTO` or the sqlite3 `.backup` command; with Kalzit
  stopped, copy `kalzit.db`, `kalzit.db-wal` and `kalzit.db-shm` together. Back up the key file
  too. To restore, copy the files back instead of moving them, and do not use tools that copy
  permissions (`robocopy /COPYALL`, `xcopy /O`).
- Closing the console window or shutting down Windows stops Kalzit cleanly.
- Dashboards: collapsible rows that you can reorder by dragging or with the arrow keys; panels
  and rows that repeat for each selected value of a variable that allows several values.
- Annotations on every time chart: write them with Ctrl+click, the A key or the panel's
  "Annotate" button, with text and tags; annotation queries add marks from a data source.
- Links under the dashboard title (to addresses or to dashboards with a tag) and data links in
  panel headers, with variables filled in; only web, mail and local addresses are allowed.
- Panels can have their own time range and a time shift, shown in their header.
- Kiosk mode, TV mode with controls that hide themselves, a single panel in full screen, and
  playlists that show dashboards one after another.
- Library panels: one panel shown by many dashboards, with a warning before a change reaches all
  of them.
- The dashboard model as JSON, checked by the server; export and import of dashboards with a
  confirmed mapping of data sources; copy a panel to another dashboard and "save as".
- Steps on query results, in the panel editor and in Explore: calculated fields with formulas
  (also across two joined queries, such as revenue per session), statistics (sum, mean, median,
  percentiles, standard deviation), trend line, moving average, correlation, comparison with the
  previous week, month or year, group and pivot. Each step can be moved, turned off and removed,
  with a preview after every step; the queries themselves stay as they are.
- Export a panel or an Explore result as CSV (semicolon and decimal comma in German, for Excel),
  Excel workbook or JSON, with the steps applied. Editors and up may export; viewers may not, and
  every export is in the audit log.
- Command palette (Ctrl+K, on macOS Cmd+K): find dashboards, folders, data sources,
  administration sections and recently opened dashboards by a few letters of their name, and
  run actions such as a new dashboard, Explore or the theme. It only lists what you may open.
- The start page greets you with the organization in numbers (dashboards, data sources,
  members and the changes of the last seven days, as far as you may see them) and shows your
  starred and recently opened dashboards as cards you can star or open for editing. Star a
  dashboard from its page or its card.
- The sidebar starts with a card for your organization that opens its settings, members and
  teams; Search sits in the navigation and also opens with /. The button that collapses the
  sidebar sits at the top left of the page, before the breadcrumbs (also Ctrl+B). A first-steps card (add a data
  source, create a dashboard, invite a colleague) ticks off what is done and can be hidden.
- Breadcrumbs on dashboards, folders, data sources and the administration.
- Press ? for the keyboard shortcuts of every area.
- Personal preferences on your account page: language, theme, time zone, start dashboard and
  first day of the week. They apply at once, can be undone and follow you to every browser. All
  times in Kalzit follow the chosen time zone: lists, tables, charts, time ranges such as "today"
  and the audit log's day filter. A language or theme you pick on the sign-in page becomes your
  preference when you sign in, unless you already have one.
- Saved, failed and undo messages appear in one place at the bottom of the window and are read
  out by screen readers.
- A stop gives open requests 10 s and then up to 5 s to close the database. With Docker, use
  `docker stop -t 20` or `docker run --stop-timeout 20` (in Compose `stop_grace_period: 20s`),
  since the default of 10 s can cut the clean stop short.
- Dashboards, Explore and lists use the whole width of the window; forms and settings keep a
  comfortable reading width. The interface uses calm graphite surfaces with white cards in the
  light theme, softer corners and a denser dashboard grid.
- Panel actions appear when you point at a panel or reach it with the keyboard, so a dashboard
  shows titles and data instead of rows of buttons; on touch screens they stay visible.
- Adding a data source shows each kind as a card with the product's logo and a short
  description; the list and the form show the same logo next to the kind.
- Visualizations: gauge, bar gauge, pie and donut, heatmap, histogram, state timeline, status
  history and text (Markdown with dashboard variables), next to time series, stat, bar chart and
  table. A picker shows each type with a small drawing and offers those that fit the query first.
- Field options for every panel: units per language (data sizes, rates, durations, currencies,
  SI units, temperatures, dates), decimals, min and max, thresholds, value mappings, a text for
  missing values, display names, colors and overrides per field; legends as list or table with
  last, min, max and mean, and tooltips for one series, all or none.
- Tables: column filters (text, or `>`, `<`, `=` and `!=` on numbers), pages, colored text or
  background, gauge cells and links per column.
- Patterns in overrides and value mappings use RE2 syntax (no lookaround or backreferences); a
  dashboard with another pattern is not saved, and the message names the panel.
- The network, hierarchy and path panels appear in the picker with a drawing and a short
  description, and their options are checked when a dashboard is saved, like those of every other
  panel.
- Units typed by hand in panels from before the field options stay a plain suffix after the value.
- Restoring an older dashboard version checks the options of every panel edited since that
  version; a version whose options today's rules refuse cannot be restored once that panel has
  changed. Dashboards from before keep opening, querying and saving while their panels are left
  as they are.
- The sign-in and setup pages have the graphite look of the app: on wide screens a quiet panel
  with the Kalzit mark, the product line and a drawing of the three result shapes stands next to
  the form. Password fields can show what you typed and warn when Caps Lock is on; setup groups
  its fields into three steps and rates a new password while you type it. Signing out is
  confirmed on the sign-in page, and too many failed sign-ins say how long to wait.
- Query editors for Elasticsearch and OpenSearch, CSV and JSON files and HTTP JSON, in Explore and
  in the panel editor. Search sources take an index picked from the cluster or typed as a pattern,
  a Lucene query or Query DSL with suggestions for the index's fields, ready-made aggregations,
  the number of hits and the time field; aggregations become a table. File sources show the file,
  how it is read and its columns. HTTP JSON sources take a path below the source's URL, query
  parameters and the path to the documents, with a preview of the request. A query the server
  would refuse says why before you run it.

- Editing and adding a panel happen on a page of their own, with an address you can reload or
  share (`.../panels/<id>/edit`, `.../panels/new`): the bar with Back, the time range, Refresh,
  Discard, Apply and Save dashboard; the preview on top with a table view; the queries and steps in
  tabs below; the options on the right in groups you can fold, the visualization first. Drag the
  separators or move them with the arrow keys; the editor remembers their place and whether the
  options are folded away. Back, Apply and Esc keep the change in the dashboard until you save it;
  Discard and the browser's back button leave the panel as it was, after asking when something
  changed. A new panel starts with an empty query and joins the dashboard only on Apply or Save.
  A reload of the tab keeps your unsaved changes; leaving the dashboard with unsaved changes asks
  first.
- Queries in the panel editor can be folded, duplicated and hidden; a hidden query stays with the
  panel but does not run.
- A panel's actions (its links, view alone, annotate, inspect, export, edit, duplicate, copy and
  remove) are in one menu behind a button in its title bar, so narrow panels keep a one-line
  title.
- Typing in the panel editor and dragging panels stay smooth on slow computers: a key redraws
  only the query you type in, and a dragged panel follows the pointer, shows where it will land
  and moves the others once you let go. Queries run on Ctrl+Enter, the run button or when you
  leave a changed query.
- Bar charts show several series side by side per category with a small gap between the bars,
  write large axis values short (25 k, 200 k), can hide the category names and write values above
  bars wherever they fit; the legend can stand on the right as a list or a table. A bar chart of
  one series takes the quiet monochrome look of the time series.
- Bar gauges draw one bar per row for a result with names and values, with each value right after
  its bar's end; the bars share the panel's height, the value grows with them and can take the
  bar's color or be hidden, and names go before or above the bars or can be hidden.
- Pie charts fill their panel and write percentages on the slices where they fit (or beside the
  circle, as before); the legend table on the right lists the value, the share or both, without a
  darker band behind its header.
- Text panels read like a short document: more space between paragraphs and list items, a relaxed
  line height and quieter list markers.
- Time series have a graph style under the field options: lines, bars or points; linear, smooth
  or stepped lines; line width and solid, dashed or dotted lines; no fill, a solid fill or
  hatching, with a fading, hue or threshold gradient; points always, never or when there is room,
  in a size of your choice; gaps connected always or up to a duration, and lines broken where
  points lie too far apart; series stacked normally or to 100 % in groups; bar alignment and
  width. Every option can be set per series through an override.
- A time series with one series draws it in the quiet look: a light line on dark (dark on light),
  smooth, with a fading hatch beneath and only horizontal grid lines. Mark a series as comparison
  series and it is drawn muted and dashed beside it; several series keep the color palette.

## Fixed

- Bar gauges with one field per bar compare fields of the same unit on one scale; before, every
  bar of a reduced value could look full.
- The tooltip of bar charts, bar gauges and pies no longer hides the name of the item in the
  middle of a chart.
- Panels and Explore queries on CSV and JSON files and HTTP JSON sources run instead of saying
  that there is no query yet.
- Creating or changing a library panel checks its options and field options like a dashboard save, and names the panel and the option it refuses; a stored library panel can still be saved while those stay as they are.

## Checklist for Windows (manual)

- Install as a service with a virtual account, start it, and check that
  `%ProgramData%\Kalzit\data` exists and only SYSTEM, Administrators and the service account have
  access (`icacls "%ProgramData%\Kalzit\data"`).
- Check that `%ProgramData%\Kalzit` grants Users read access only.
- Grant Users write access to the data directory (`icacls ... /grant Users:(W)`), restart the
  service, and check that it refuses to start with a message that names `icacls`; remove the
  entry again and check that it starts.
- Open the data directory in a non-elevated Explorer, click "Continue", restart the service and
  check that it refuses to start; remove the added entry with `icacls ... /remove <account>`.
- Exclude `kalzit.db`, `kalzit.db-wal` and `kalzit.db-shm` in the data directory from virus
  scanning (real-time protection), and check that saving still works quickly afterwards.
- Start Kalzit in a console window, close the window, and check that `kalzit.db-wal` is gone
  afterwards (a clean stop).
- Export a dashboard in Edge, import the file again and check that its data sources are matched
  by kind and name.
- Play a playlist in TV mode for a few minutes and check that the controls hide and come back
  with the mouse or a key.
- In Edge on a 1920 px wide screen, open a dashboard and check that it fills the width next to the
  sidebar; drag the window narrower and check that the charts follow without flickering.
- Stop Kalzit, back up `kalzit.db`, `kalzit.db-wal` and `kalzit.db-shm` together, start it again
  and check that sign-in works.
- Back up while running with `sqlite3 kalzit.db ".backup backup.db"` and restore the backup into
  a fresh data directory together with the key file, copying (not moving) the files.
- Allow a folder under `datasources.file_dirs`, add a CSV file saved by German Excel from it as a
  data source (`C:\Daten\umsatz.csv`), and check in Explore that its columns and decimal commas
  read right; a file outside the folder is refused.
- Export a panel as CSV in German and open it in Excel by double-click: umlauts, decimal commas
  and columns are right; open the Excel export and check that times and numbers are cells of
  their type.
- Open the command palette with Ctrl+K in Edge and Firefox on Windows, and check that it opens
  instead of the browser's address search, also with a German keyboard layout.
- Press ? with a German keyboard layout (Shift+ß) and check that the shortcuts help opens.
- Press / with a German keyboard layout (Shift+7) outside a text field and check that the search
  opens.
- Pick a time zone other than the computer's on the account page and check that times on the
  dashboard list, in a time series chart, in "Today" and in the audit log's day filter follow it.
- In Edge, open a panel in the editor, drag both separators and move them with the arrow keys,
  change the title, reload the page and check that the editor opens again with the same sizes and
  the changed title; press Esc and check that the dashboard shows the change as unsaved. Add a new
  panel, press the browser's back button and check that Kalzit asks before dropping it.
- On the sign-in page in Edge, turn Caps Lock on, type into the password field and check that the
  warning shows below it and goes away when Caps Lock is off; check that Edge's own reveal button
  does not appear next to Kalzit's.
- In Edge, open a dashboard with a bar chart of several series, a bar gauge and a pie with their
  legends on the right; check that the bars stand side by side with short axis values, that the
  gauge's values grow and shrink with the panel's height, and that the pie's percentages sit on
  its slices; make the window narrow and check that the legends move below the drawings.
- In Edge with Kalzit's high contrast theme, open a time series with one series and check that
  the hatch under the line stays visible; switch Windows' "Animation effects" off and check that
  the charts still draw at once.
