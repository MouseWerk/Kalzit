# Kalzit 0.1.0

## Improved

- The built-in SQLite database now runs in WAL mode: reading never waits for a change being
  saved, and many changes at once no longer end in errors. When the database is briefly busy, the
  server answers "try again in a moment" and the UI retries on its own.
- The first start of this version switches an existing SQLite database to WAL mode. For that it
  needs the database to itself: stop any other program that has `kalzit.db` open (a backup tool, a
  second Kalzit) before the update.
- A SQLite database on a network drive is refused at start with a clear message; use PostgreSQL
  for shared storage or several servers.

## Fixed

- Under heavy load on Windows, saving could fail with "Something went wrong on the server".

## Checklist for Windows (manual)

- Exclude `kalzit.db`, `kalzit.db-wal` and `kalzit.db-shm` in the data directory from virus
  scanning (real-time protection), and check that dashboards still save quickly afterwards.
- Stop the service, back up `kalzit.db`, `kalzit.db-wal` and `kalzit.db-shm` together, start it
  again and check that sign-in works.
