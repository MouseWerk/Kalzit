# Kalzit 0.2.0

## Improved

- Saved analyses: keep an Explore query with its analysis steps and chosen view under a name, in
  folders and team spaces with the same sharing and rights as dashboards, a version history, the
  trash, and dashboard panels that stay linked to the analysis. Viewers open and run analyses
  shared with them; changing a query still needs the right to query its data source.
- Explore has Save (Ctrl+S) and Open (Ctrl+O) for saved analyses: name, location with who will see
  it, an optional description, and the choice to keep the time range; once saved, a "Changed" mark,
  save as, rename, move, versions and discarding changes.
- "Saved" under Explore in the sidebar lists the saved analyses by folder and team space, with
  search, filters by data source and creator, where each is used, and a trash of its own.
- A new dashboard panel can start from a saved analysis, with a live preview, linked (it follows
  the analysis) or as a copy, or from a copy of another panel.
- A newer version saved by someone else is shown right away in Explore; saving over it asks first
  and offers to save a copy, load the newer version or overwrite it.
- Saved analyses can be found in the command palette (Ctrl+K).

## Checklist for Windows (manual)

- Saved analyses on Windows: save an analysis in a folder, open it as a viewer and run it, link it
  into a dashboard panel, change the analysis and check that the dashboard shows the change, and
  check that moving the analysis to the trash is refused while the dashboard links it.
