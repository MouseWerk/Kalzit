# Kalzit 0.2.0

## Improved

- Saved analyses: keep an Explore query with its analysis steps and chosen view under a name, in
  folders and team spaces with the same sharing and rights as dashboards, a version history, the
  trash, and dashboard panels that stay linked to the analysis. Viewers open and run analyses
  shared with them; changing a query still needs the right to query its data source.
- Field distribution for MongoDB counts the whole result in the database, not only the loaded
  page: values, missing and null fields, types, the most common values, minimum and maximum and
  the histogram cover all documents, and the panel says whether it shows all documents of the
  result or the loaded ones. Fields with dots, umlauts or emoji in their names are counted as
  stored.
- Live updates: the server pushes new query results over a WebSocket as soon as MongoDB reports a
  change (replica sets), and runs other queries again at a set interval.

## Checklist for Windows (manual)

- Saved analyses on Windows: save an analysis in a folder, open it as a viewer and run it, link it
  into a dashboard panel, change the analysis and check that the dashboard shows the change, and
  check that moving the analysis to the trash is refused while the dashboard links it.
- Field distribution on Windows: in Explore, run a MongoDB query with more documents than one page,
  choose the field distribution and check that it says "Across all N documents of the result" with
  N above the loaded count; switch fields quickly and check that only the last field's numbers
  show; filter by a common value and check the new `$match` stage; as a viewer, open a dashboard
  with a distribution panel and check the same numbers.
- Live updates: open a dashboard with live updates on Windows, change data in its source and see
  the panel update; stop the service and check that the browser shows that the server restarts.
