# Kalzit 0.2.0

## Improved

- Saved analyses: keep an Explore query with its analysis steps and chosen view under a name, in
  folders and team spaces with the same sharing and rights as dashboards, a version history, the
  trash, and dashboard panels that stay linked to the analysis. Viewers open and run analyses
  shared with them; changing a query still needs the right to query its data source.

## Fixed

## Checklist for Windows (manual)

- Saved analyses on Windows: save an analysis in a folder, open it as a viewer and run it, link it
  into a dashboard panel, change the analysis and check that the dashboard shows the change, and
  check that moving the analysis to the trash is refused while the dashboard links it.
