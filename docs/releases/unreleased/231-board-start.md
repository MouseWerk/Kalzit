## Improved

- The start page shows the status of your data sources from their last connection test (with
  the time it took, or "unreachable"), and hints that need a look: a new Kalzit version for
  server administrators, a source that has been unreachable for some time, a source no dashboard
  uses. "Recently changed" now says what changed ("Lea saved “Sales by region”"), and the quick
  start offers Create a panel, Connect a data source, Explore data and Check for updates.

## Checklist for Windows (manual)

- Under Datenquellen, test every source, then stop one source's database and test it again; open
  Start: "Datenquellen-Status" lists the stopped source first as "nicht erreichbar" and the others
  with their milliseconds, and "Hinweise" says the stopped source is not reachable, with "Prüfen".
