## Improved

- Dashboard settings > Variables offers two more kinds: **Time intervals** (a list such as 1m, 10m,
  1h) and **Constant** (one fixed value that queries use and viewers do not see in the bar).
- Variables can be moved up and down with arrow buttons and duplicated.
- Changing the time range or a variable's value while editing no longer changes the saved
  dashboard by itself: the save dialog asks whether the range and the values on screen become the
  new defaults, and only when they differ from the saved ones.
- Dashboard settings > General has a folder field to move the dashboard and a **Delete...** action
  for people who may delete it.
- Dashboard settings > Versions lists the versions right there, with compare and restore.
- Your account shows the teams you belong to in the current organization.
