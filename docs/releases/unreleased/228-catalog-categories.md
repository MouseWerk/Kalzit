## Improved

- The plugin catalog has a category tree: Data sources and Panels, each with the categories the
  list names (such as Databases or Maps). **Load via proxy** in the catalog's settings decides
  whether the list and plugin downloads use the outbound proxy.

## Checklist for Windows (manual)

- Plugins > Catalog with an outbound proxy set: turn **Load via proxy** off and on, press
  **Refresh now** each time, and check that the list loads directly and through the proxy.
