## Improved

- A line that is cut with an ellipsis shows its full text as a tooltip only while it is actually
  cut: the e-mail address of a member, the lines under a report's name and the label of a figure
  tile no longer repeat in a tooltip what is already on screen.
- Plugins: the page of an app says how an app runs, in a sealed-off frame in the browser with the
  rights of the person signed in, instead of the text for a panel, and no longer shows an empty
  "Result shapes" row.
- Backups: the three tiles for the last backup, the next one and the target look like the figure
  tiles of the other pages, and their values start at the same height.
