## Improved

- Saved analyses look like their board: "Explore / Saved analyses" at the top, the trash with
  its count and "New query in Explore" in the header, the number of analyses beside every folder,
  an "Owner" column with initials, and a new sort "Last opened" that puts what you opened last
  first. An empty folder offers "Move from another location", and a search without matches says
  how many the other locations hold.

## Checklist for Windows (manual)

- Under Explore > Saved, choose "Last opened" as the sort, open an analysis in Explore, go back:
  it is now first. Select an empty folder and use "Move from another location": the analysis moves
  there and the folder counts change.
