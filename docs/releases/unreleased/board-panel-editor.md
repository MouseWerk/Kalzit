## Improved

- In the panel editor each query shows, after a run, how many rows (documents, or nodes and
  edges) it returned and how long the server took, with its own Run button and the Ctrl+Enter
  hint; "Add query" sits below the queries.
- The panel editor's options can be searched, and the views "Changed" and "Overrides" show only
  the options that differ from a new panel's defaults or only the overrides.
