## Improved

- Graph panels have an **Export** menu with the image formats **PNG**, **SVG** and **PDF**, and the data formats **GraphML**, **JSON** and two new **CSV** files for nodes and edges.
- SVG images keep every label as text and stay sharp at any size; PDF images are a single small page of vector shapes.
- The image dialog lets you choose the visible part, the whole graph or the selection, the background, the legend and the title, data source and time range.
- GraphML files now carry where each node is drawn, and the data formats can export only the visible nodes.
- Everyone who may see a panel can save it as an image. GraphML, JSON and CSV still need the right to export data, and the menu says so when you do not have it.
