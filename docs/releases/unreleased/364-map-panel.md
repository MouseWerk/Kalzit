## Improved

- New Map panel: rows and documents with coordinates and graphs with point values or two number properties appear on a map, with edges as lines, near nodes bundled, a table view, and a list of what has no coordinates.
- Without map images, maps draw the built-in country and region outlines (Natural Earth, public domain); no request leaves your server.
- Administration > Map sets up one source of map images for the whole server, with Test map images, one Save and an error at each field; switching it off applies at once with undo. Map images always load through the Kalzit server, through the outbound proxy and a bounded cache, also on public links that show a map.
