# Kalzit 0.4.1

## Improved

- "Add to dashboard" and "Save as panel" under an answer in Ask show the whole query once more,
  read-only, before you save it.
- The AI part of an HTTP JSON or plugin data source explains that Ask runs only the saved queries
  of panels on it.

## Fixed

- Excluding a field or lowering the row limit now also applies to chats already kept in Ask:
  their results lose the newly excluded values and the rows beyond the limit. Where an answer's
  results show less than the assistant saw, its words are withheld as well, with a note, and are
  not sent to the provider again; so are the words of every later answer in that chat.
- Ask no longer runs queries of its own on HTTP JSON or plugin data sources, where such a query
  could carry data out of the chat; it runs the saved queries of their panels instead.
- Ask no longer runs a panel whose saved query names an excluded field, or whose steps read one
  (to rename, join, group, pivot or compute from it). Excluded fields are also replaced in the
  renamed columns of a joined result.
- Ask runs panels of HTTP JSON or plugin sources only with relative time ranges such as "last 7
  days", never with exact times the assistant picked.
- Queries on PostgreSQL can no longer call the HTTP functions of the pgsql-http extension.
- Error messages of a panel with steps that Ask ran could quote values of a source with excluded
  fields; they are now cut like other error messages.
- The hint under "Excluded fields" now says that values used as the id of a graph node or edge, or
  as a document's `_id`, are not replaced.

## Checklist for Windows (manual)

- Ask on Windows: open a SQLite source to AI, ask "Which e-mail addresses are in the customers
  table?" and wait for the answer with the addresses. Add `email` to "Excluded fields" on the
  source, open the chat again and check that the addresses show as `[excluded]` and the answer's
  words are replaced by the note "Answer withheld because access to its data changed". Ask a
  follow-up question and check that the answer does not repeat an address.
- Add an HTTP JSON source (for example `http://localhost:8080/`), open it to AI and check the
  note in its AI part. In Ask, ask about it and check that the assistant says it cannot query it
  directly.
- Under an answer with a query, press "Add to dashboard" and "Save as panel" and check that each
  dialog shows the whole query, read-only.
