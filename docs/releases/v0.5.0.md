# Kalzit 0.5.0

The parts of 0.5.0 that were finished earlier shipped with 0.4.1; see its notes.

## Improved

- Hierarchy panels can use ELK (the Eclipse Layout Kernel) instead of Kalzit's own layered layout:
  under Layout in the panel options, pick "ELK layered" and set the direction, node and layer
  spacing and the edge routing. Kalzit's layout stays the default; ELK loads only when a panel
  uses it, gives the same result the same layout every time, and if it cannot run the panel shows
  Kalzit's layout and says so.

## Fixed

## Checklist for Windows (manual)

- Open a dashboard with a hierarchy panel on the Windows server in Edge, set Layout to "ELK
  layered" and Direction to "Left to right", save, and check that the tree is drawn from left to
  right without a note that ELK could not run; reload and check that it looks the same.
