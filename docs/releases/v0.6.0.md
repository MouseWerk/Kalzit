# Kalzit 0.6.0

## Improved

- While a panel, the panel editor's preview or a result in Explore waits for its first answer, it
  shows a quiet placeholder in the shape of the panel instead of a "Loading" line. The shimmer on
  it stands still when the system asks for reduced motion.
- Explore keeps the steps beside the result on laptop screens, also with the sidebar open; in a
  narrow window they move under the result and use its whole width.
- Step cards in Explore and the panel editor are compact and have a quiet edge, so each step stands
  apart from the next.
- A panel, the panel editor's preview, a saved analysis and Explore offer "Try again" ("Erneut
  versuchen") when a data source fails; so does Explore when its list of data sources could not
  be loaded.
- A wrong user name, password or token now says so ("The data source refused the sign-in") for
  PostgreSQL, MySQL, MariaDB, SQL Server, ClickHouse, Neo4j, MongoDB, Prometheus, Loki, InfluxDB,
  Elasticsearch, OpenSearch and HTTP JSON sources, instead of passing on the database's own error
  text.
- SQL Server, Neo4j and Memgraph sources close connections that sat unused for five minutes, also
  when no query comes, and never hand out a connection the server has closed or that broke.
- Charts and graph panels stay readable with Windows high contrast (forced colors): lines, nodes,
  edges, axes and labels are drawn in the system colors, and they redraw when high contrast is
  turned on or off.
- Kalzit's own requests to the internet (plugin catalog, update checks and downloads, Let's
  Encrypt and the AI providers) can go through an outbound proxy, set under Settings > Network,
  HTTPS and proxy, with a list of hosts reached directly and an optional sign-in whose password is
  stored encrypted. Data sources keep their own connections.
- Plugins that serve a data source close what they kept open for it as soon as the data source is
  changed or moved to the trash.

## Fixed

- A redirect that Kalzit refuses to follow (HTTP JSON, TigerGraph) is shown as a refused request,
  as for Elasticsearch, InfluxDB and Loki, instead of as a failure of the data source.
- The debug log of the MongoDB check when saving a source no longer repeats a password that the
  server's error contains.
- Graph panels no longer lose their node labels in Windows high contrast, where the label
  background took the text color.
- The plugin tables (installed plugins, trusted keys, plugins of an organization) can be scrolled
  sideways with the keyboard on narrow screens, and the trusted keys no longer widen the page on a
  phone.
- In the plugin catalog on a narrow window, the "Only trusted publishers" check box keeps enough
  room from the categories above it to be tapped reliably.
- Fragen (Ask) on a phone: long data source names in the side panel are shortened instead of
  pushing the page wider than the screen.
- Screen readers no longer announce the panel editor's options twice, and the selection and pinned
  parts of a graph node's details are no longer repeated as page regions when several graph panels
  show them.
- Saving a library panel or a saved analysis with a plugin panel now checks its options against
  what the plugin declares, as dashboards already did, and names the panel, the plugin and the
  option that does not fit.
- Plugin packages that would unpack to far more than their size (zip bombs) are refused by the
  `kalzit-plugin` tool as they already were by the server.

## Checklist for Windows (manual)

- Open Explore in Edge at 1280 px wide with the sidebar open, run a query and add two steps: the
  steps stay beside the result. At 1024 px they move under it.
- Stop a data source's database, open a dashboard with a panel on it: the panel shows the error
  with "Try again"; start the database again and choose it: the panel draws.
- Add a SQL Server source with a wrong password and choose Test connection: it says the data
  source refused the sign-in and does not show the password. Correct the password and test again.
- With a working SQL Server or Neo4j source, run a dashboard query, restart the database service
  and run the query again: it answers without an error. Leave the source unused for more than five
  minutes and check in the database's session list that Kalzit's idle connections are gone.
- Add a Prometheus or Elasticsearch source with a wrong password or token: Test connection says
  the data source refused the sign-in.
- Turn on a contrast theme (Settings > Accessibility > Contrast themes), open a dashboard with a
  time series and a graph panel: lines, nodes, edges and labels are visible in the theme's colors;
  turn the contrast theme off again and the panels return to Kalzit's colors without a reload.
- Set Settings > Network, HTTPS and proxy > Outbound proxy to a proxy on the network (for example
  `http://proxy:3128`), turn on the plugin catalog and refresh it: the catalog loads, and the
  proxy's log shows the request. Undo the proxy setting and refresh again: it loads directly.
