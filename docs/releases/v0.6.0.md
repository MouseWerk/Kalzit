# Kalzit 0.6.0

## Improved

- Lists of dashboards, saved analyses, folders, playlists, library panels, service accounts,
  organizations, roles and teams sort alphabetically by the rules of the language: "Ö" sits next
  to "O", "ß" sorts like "ss", and upper and lower case count the same. The order is the same with
  SQLite and PostgreSQL.

## Fixed

- Paging through a long list of dashboards, saved analyses, library panels, playlists or service
  accounts no longer repeats or skips entries on PostgreSQL.
- The first start after the update prepares the new order for every title and name. With
  hundreds of thousands of dashboards and analyses, raise "Health check after an update" on the
  Updates page before updating, so the new version is not rolled back while it does that.

## Checklist for Windows (manual)

- Update a Windows installation with dashboards titled "Äpfel", "Apfel", "Öl", "Ost" and "Straße":
  after the update, Start and the dashboard list show them as Apfel, Äpfel, Öl, Ost, Straße, in
  German and in English.
