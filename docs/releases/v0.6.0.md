# Kalzit 0.6.0

A fix-and-polish release: every screen follows its design board, export and image export work for
every shape, Explore helps you start from an empty editor, graph panels make room for their labels,
and Kalzit runs under a sub-path, on 64-bit ARM Linux and with Prometheus metrics. The user guide is
also in German.

## Improved

- The start page shows the status of your data sources from their last connection test (with
  the time it took, or "unreachable"), and hints that need a look: a new Kalzit version for
  server administrators, a source that has been unreachable for some time, a source no dashboard
  uses. "Recently changed" now says what changed ("Lea saved “Sales by region”"), and the quick
  start offers Create a panel, Connect a data source, Explore data and Check for updates.
- Pages load faster: setup, sign-in and the help pages load only when they are opened, the browser
  fetches only the language Kalzit is shown in (and the other one when you switch), and the panel
  of the time range picker loads when it is first needed.
- Explore looks like its board: documents get the tabs "Documents", "Schema" and "Table
  (projection)", with how many came back and how long the query took beside them; "Share" copies
  a link to the query on screen for people in your organization; steps are compact cards with a
  quiet edge that open on a click, so each step stands apart from the next, in Explore and in the
  panel editor.
- "Add step" in Explore opens a searchable catalog that says what each step does and which shape
  goes in and out.
- Explore helps you start from zero with every kind of data source: when a source is open and the
  editor is empty, "Start here" says in plain words what the source holds and offers ready
  examples, such as the first 100 rows of a table, counts per value, nodes with a label, the rate
  of a metric or the latest log lines with an error. Each one fills in a safe, read-only query with
  the names of your own tables, collections, labels or metrics and runs it; "Show the query" shows
  it before you use it.
- Explore has a schema list beside the result: "Show rows", "Count" and "Show structure" on a
  table, collection, node label, metric or index put the matching query into the editor and run
  it.
- Each query language has a searchable cheat sheet in Explore (button "Cheat sheet", Shift+F1, or
  Ctrl+/ / Cmd+/ outside the editor, where those keys stay the comment toggle): filter, sort,
  limit, group and count, join or traverse, time range and variables, each with a short
  explanation and "Insert". It also says how Kalzit's time range and dashboard variables work with
  that source.
- When a query fails because of an unknown table or column, a syntax error or a write, Explore
  adds a plain-language hint next to the error, with a link to the cheat sheet or the schema. A
  result cut off at the row limit suggests a time filter.
- "Build without writing a query" in Explore runs a first query and leads to the steps; under a
  group step on a SQL source, "Show the query of this step" shows the SQL that does the same, and
  can replace the step with it.
- With AI on, "Ask in plain language" in Explore opens Fragen with the source already chosen.
- Explore keeps the steps beside the result on laptop screens, also with the sidebar open; in a
  narrow window they move under the result and use its whole width.
- Small tips appear once, at the moment they help (after a first result, for the Ctrl+Enter
  shortcut, for steps). Close one with a click, or turn all tips off under Account > Preferences >
  Tips; the choice and the tips already seen follow you to every browser.
- Saved analyses look like their board: "Explore / Saved analyses" at the top, the trash with
  its count and "New query in Explore" in the header, the number of analyses beside every folder,
  an "Owner" column with initials, and a new sort "Last opened" that puts what you opened last
  first. An empty folder offers "Move from another location", and a search without matches says
  how many the other locations hold.
- Export keeps the shape of a result: documents export as NDJSON (one document per line) or
  JSON, with their fields in the order the database stored them, and graphs as GraphML for Gephi,
  yEd and Cytoscape or as JSON with their paths. Tables keep CSV, Excel and JSON. With several
  results the export dialog names each one with its shape and offers only the formats it can
  have; a table of documents or of a graph comes from a step, as on the screen.
- "Save image (PNG)" in a panel's menu saves what the panel shows as a sharp picture, for
  every kind of panel, graph panels included, in the theme on screen.
- "Load more documents" continues a result that was cut off for Elasticsearch and OpenSearch
  hits and for JSON and NDJSON files, as it already did for MongoDB, and now also under a
  document panel on a dashboard: viewers page through the panel's stored query. A page marker
  only works for the person and the query it was made for.
- Data links from document fields and node and edge properties: the document explorer, the
  document card and the graph panels take links on a field path or a property ("Datenlinks" in
  the panel options), with the value filled in and encoded for the address. A link opens a web
  address or another dashboard with the value as its variable
  (`/dashboards/<id>?var-customer=${__value}`); a dashboard address now carries starting values
  for its variables as `var-name`. Only `https://`, `http://` and pages of Kalzit are allowed.
- Dashboard edit mode matches its design: an "Editing" tag after the dashboard's name instead of a
  status line, the buttons "Settings", "Finish editing" and "Save dashboard", and an "Add panel or
  row" button at the end of the canvas that opens the Add pane.
- Panel shortcuts while editing: E opens the selected panel in the editor, Ctrl+D duplicates it,
  Ctrl+C copies it, Ctrl+V pastes a copied panel (also into another dashboard, or from the Add
  pane) and Delete deletes it (Backspace too on a Mac, where Cmd takes the place of Ctrl).
  Duplicating, pasting and deleting offer Undo, the result is announced to screen readers, the
  keys do nothing while you type in a field or query editor, and the shortcut help lists them.
- Dragging a panel on a dashboard in edit mode no longer redraws the charts of the other panels
  while the drag passes them, so the drag stays smooth on slower computers.
- The inspector's own time range for a panel sits behind an "Override time range" switch; turning
  it off and on again while the panel stays selected brings the values back.
- The dashboard rail names its tools as on the design: "Filters and variables", "Annotations
  on/off", "Share and copy link", "Export (JSON)", "Versions and history", "Dashboard info" and
  "Dashboard settings".
- Changing the time range or a variable's value while editing no longer changes the saved
  dashboard by itself: the save dialog asks whether the range and the values on screen become the
  new defaults, and only when they differ from the saved ones.
- Dashboard settings > Variables offers two more kinds: **Time intervals** (a list such as 1m, 10m,
  1h) and **Constant** (one fixed value that queries use and viewers do not see in the bar).
  Variables can be moved up and down with arrow buttons and duplicated.
- Dashboard settings > General has a folder field to move the dashboard and a **Delete...** action
  for people who may delete it, and Dashboard settings > Versions lists the versions right there,
  with compare and restore.
- In the panel editor each query shows, after a run, how many rows (documents, or nodes and
  edges) it returned and how long the server took, with its own Run button and the Ctrl+Enter
  hint; "Add query" sits below the queries.
- The panel editor's options can be searched, and the views "Changed" and "Overrides" show only
  the options that differ from a new panel's defaults or only the overrides.
- Panels of plugins act like the built-in ones: a time range picked in one sets the dashboard's
  time range as the time picker does, a variable it sets changes only if the dashboard has it and
  it takes the value, and under "Clicks and selection" in the panel editor you choose which
  variable a click or a selection in the panel sets, and from which column, path or property.
- While a panel, the panel editor's preview or a result in Explore waits for its first answer, it
  shows a quiet placeholder in the shape of the panel instead of a "Loading" line. The shimmer on
  it stands still when the system asks for reduced motion.
- A panel, the panel editor's preview, a saved analysis and Explore offer "Try again" ("Erneut
  versuchen") when a data source fails; so does Explore when its list of data sources could not
  be loaded.
- Graph panels make room for their labels: a network spreads its nodes over the panel, as far as the
  panel has room, so nodes do not lie on each other and the names that fit show beside their node,
  also in a short or narrow panel ("UPS A1" next to "UPS A2"). A label that would still cover a
  node, another label or the edge of the panel waits until zooming gives it room. Small panels show
  fewer labels at once, and in a short panel the nodes are drawn smaller.
- Nodes in graph panels have a shape per label, circle, square or diamond, as a second cue next
  to their color, and the legend shows it. A label keeps its shape when the data is refreshed or
  the explorer adds nodes, and the panel options ("Color and shape per label") can give a label a
  shape of its own. With Windows high contrast, where nodes take the system colors, the shapes and
  the legend still tell the labels apart.
- Graph panels have tidier tools: zoom as icons, "Show all", Graph and Table as one switch, and
  the explorer with its icon. A hierarchy offers its direction (top to bottom or left to right)
  right in the panel. The legend under a graph says what the node sizes stand for, the panel names
  the selected node with Esc to clear it, and Undo, pin and "Show only the selection" show their
  keys.
- An empty graph result and a hierarchy too large to lay out offer "Edit query" to those who may
  edit the dashboard.
- Paths show their total weight when every edge carries a weight, cost or distance.
- Cypher may call the graph algorithms of Neo4j GDS (`stream` and `stats` modes) and Memgraph
  MAGE that only read, from a reviewed list; writing modes, graph projections and APOC stay
  refused. Graph panels with more than 2,000 nodes get their communities from GDS or MAGE when
  the source has it and you may query the source.
- Charts and graph panels stay readable with Windows high contrast (forced colors): lines, nodes,
  edges, axes and labels are drawn in the system colors, and they redraw when high contrast is
  turned on or off.
- Very wide tables with hundreds of columns scroll smoothly sideways: only the columns in view are
  drawn, and the first column stays in place.
- The data source list follows its board: each source shows where it connects, its team and who
  else it is shared with, its status from the last connection test with the query latency of the
  last 24 hours, how many dashboards use it and when it was last used, and when and by whom it was
  last changed. Opening the list no longer needs a connection test to show a status. Data sources
  and Add data source say in the wording of their design that all sources are read-only.
- Filter the data source list by team, and sort it by last used or last changed.
- Each row of the data source list has a menu: open in Explore, test the connection, edit, share,
  duplicate, move to the trash.
- Select several data sources to test, share with a team, export (settings without secrets) or
  move them to the trash together; Undo brings them back.
- A data source's side panel has two new tabs: "Usage" lists the dashboards using the source with
  its queries and errors of the last day, "History" what happened to it and who did it. Under
  "Access" each team's level is changed in place and applies at once, with Undo.
- Behaviour change: new PostgreSQL and MySQL / MariaDB data sources start with the TLS mode
  "auto", which requires TLS when the database is on a public address and prefers it on a private
  or local one. Existing data sources keep the TLS mode they have.
- A wrong user name, password or token now says so ("The data source refused the sign-in") for
  PostgreSQL, MySQL, MariaDB, SQL Server, ClickHouse, Neo4j, MongoDB, Prometheus, Loki, InfluxDB,
  Elasticsearch, OpenSearch and HTTP JSON sources, instead of passing on the database's own error
  text.
- SQL Server, Neo4j and Memgraph sources close connections that sat unused for five minutes, also
  when no query comes, and never hand out a connection the server has closed or that broke.
- Lists that check rights per entry (data sources open to AI, usage, running queries, dashboards,
  playlists) and the purge of dashboards and data sources need fewer database queries in large
  organizations.
- Lists of dashboards, saved analyses, folders, playlists, library panels, service accounts,
  organizations, roles and teams sort alphabetically by the rules of the language: "Ö" sits next
  to "O", "ß" sorts like "ss", and upper and lower case count the same. The order is the same with
  SQLite and PostgreSQL.
- Fragen: the result of a query is a card of its own with Tabelle and Zeitreihe, and the answer's
  words follow under "Kurz zusammengefasst". Answers show headings, lists, tables and code as
  formatted text; a link that would leave Kalzit shows as text with its host.
- Fragen: rate each answer as "Hilfreich" or "Nicht hilfreich"; only you see your rating.
- Fragen: "Neuer Chat" sits in the top bar, the composer shows every source it asks while none is
  chosen, and "Allowed sources" shows how many sources are asked, such as "2 of 4". The context
  column says whether the model runs in your own network or in the cloud, and whose provider it is.
- Verwaltung > KI: while AI is on, the switch sits in the status strip with since when and by whom,
  and the strip says which functions send data out of your network. The providers table shows
  where each provider runs and whether data leaves the server; "Welcher Anbieter wofür" and the
  organizations sit side by side, with each organization's AI state. "KI im Audit-Log" opens the
  audit log filtered to AI.
- The notice of what leaves the server now also names Fragen, and AI limits read "je Person"
  instead of "pro Benutzer".
- Verwaltung > Plugins: the installed plugins can be searched by name, id or publisher and
  filtered by kind (data sources, panels) and status, each with its count. The strip says how many
  data sources run out of how many and what the problems are ("1 crashed, 1 not loaded"), and the
  trust tab shows how many keys are trusted.
- "Plugin log" next to "Install from file" opens the server audit log filtered to plugin events.
- A plugin's page has a "Permissions" tab with its network targets, secrets, files, the limits of
  its process (memory, processes, connections) and its sandbox.
- A data source plugin's page shows its last health check and how its data sources answered in
  the last 24 hours: queries, errors and the 95th percentile response time.
- The page of a panel plugin shows what applies to it: its status, version, signature,
  permissions and the dashboards that show it, with links. It has no restart, process, sandbox or
  log, since a panel plugin runs no process on the server; a restart request for one is refused
  with a clear reason.
- The question before removing a plugin says that its log and temporary folder are deleted too.
- Plugins that serve a data source close what they kept open for it as soon as the data source is
  changed or moved to the trash.
- The plugin catalog has a category tree: Data sources and Panels, each with the categories the
  list names (such as Databases or Maps). **Load via proxy** in the catalog's settings decides
  whether the list and plugin downloads use the outbound proxy.
- The sign-in page can name your organization and the server above the form (Verwaltung >
  Darstellung, "Organisation auf der Anmeldeseite" and "Servername auf der Anmeldeseite"). After
  wrong credentials it says after how many attempts you have to wait and for how long at most,
  and a lockout says whether this device has to wait (with the countdown) or the address is
  locked, and at the latest until when; typing another address lifts that at once.
- Konto > Anmeldung und Sicherheit is laid out as two cards, "Anmeldung" and "Zweiter Faktor",
  with the provider or directory you sign in through ("Verknüpfte Anmeldung"), a summary of your
  methods, renaming a passkey with "Speichern" and "Abbrechen" in the row, and "Einrichten" next
  to the hint when you have no second factor yet. Your account also shows the teams you belong to
  in the current organization.
- Verwaltung > Anmeldung: "Anbieter hinzufügen" sits in the page header, the figures appear on
  the "Anbieter" tab as separate tiles and now include the share of people with a second factor.
  On "Lokale Anmeldung und 2FA" the checks sit in a column beside the settings, the allowed
  methods are two boxes, and the rule per organization is part of the second factor's card.
- Mitglieder is a table with team, sign-in (provider or password), second factor and last
  activity per person; less frequent actions such as "Passwort-Link senden", "Zweiten Faktor
  zurücksetzen…" and "Entfernen…" are in the row's menu. Open invitations are a table with how
  many days each link is still valid.
- Dienstkonten: each account and the SCIM card carry their symbol, the details close with an X,
  and revoking and deleting read in the danger tone.
- Invitation and password-reset links that expired, were used or are unknown say so in a notice
  with one clear button; signed in with another account, "Abmelden und annehmen" is the main
  button.
- The audit log (Verwaltung > Audit, and the server's) has "Export...": every event that matches
  the filters, not only the page, as CSV or JSON. Only who may read the log can export it, and
  each export is recorded in the log.
- Hints and mails name the pages where they are in the navigation: Settings > AI, Settings >
  Plugins and Settings > Sign-in.
- Form fields show their hint under the field, so fields side by side keep their inputs on one
  line whether they have a hint or not.
- Every drop-down list in Kalzit looks the same in light, dark and high-contrast themes and works
  fully with the keyboard and screen readers: arrows, Home and End, typing the first letters,
  Enter to choose and Escape to close. Long lists have a search field, long entries wrap instead
  of being cut off, and the list stays inside the window, also in dialogs and narrow settings rows.
- Icons share one style: the same line weight, size and centering everywhere, so icons line up
  next to each other and next to text. Drag handles, sort marks, tree toggles, the minus and plus
  of number fields and the up and down buttons are drawn as icons instead of text characters, and
  data sources without a logo use icons from the same set.
- Kalzit has a product icon in the browser tab (also in older browsers), on phones' home screens
  and for installed web apps, and for kalzit.exe and the installer in Windows' Apps and features.
  Each size is drawn for itself, so the icon stays sharp at 16 px.
- Kalzit can run under a sub-path behind a reverse proxy, such as `https://example.com/kalzit/`:
  set `server.base_path = "/kalzit"` and restart. Pages, API, live updates, sign-in callbacks,
  mail links and cookies all follow it ([guide](../guide/reverse-proxy.md)).
- Behind a reverse proxy, Kalzit can read the standard `Forwarded` header instead of
  `X-Forwarded-*`: set `security.forwarded_headers = "forwarded"` when your proxy writes it. Kalzit
  reads only the header you choose (`x-forwarded` stays the default) and ignores the other one.
  Your proxy must replace or remove that header when a client sends it.
- Prometheus metrics at `/metrics`: off by default, turned on in `kalzit.toml` and readable only
  with a token or from allowed networks. They count requests, query times per source kind, query
  cache hits, active sessions and plugin processes, without names, addresses or query text
  ([guide](../guide/monitoring.md)).
- A renewed TLS certificate is picked up by its content, also when the file keeps its old
  modification time or is copied in with an older one; rewriting a file with the same content no
  longer reloads it.
- Kalzit's own requests to the internet (plugin catalog, update checks and downloads, Let's
  Encrypt and the AI providers) can go through an outbound proxy, set under Settings > Network,
  HTTPS and proxy, with a list of hosts reached directly and an optional sign-in whose password is
  stored encrypted. Data sources keep their own connections.
- `kalzit db copy` moves an installation from SQLite to PostgreSQL: with the server stopped, it
  copies everything into a new, empty PostgreSQL database, decrypts every stored secret with the
  secrets key to make sure the server on PostgreSQL can read them, and compares the rows of every
  table (operator guide "Several Kalzit servers", "Moving from SQLite to PostgreSQL").
- Kalzit runs on 64-bit ARM Linux servers such as AWS Graviton, Ampere or a Raspberry Pi 4 or 5:
  each release has the program, the deb and the rpm for arm64 next to those for x64, listed and
  signed in the release manifest like them. On a server installed from a package, the Updates
  page names the package for the server's processor, also for an offline update, and shows no
  "0 kept · 0 byte" while there are no backups.
- On Windows, the service's errors also appear in the Windows event log (Application, source
  "Kalzit"), where monitoring tools can pick them up, without details such as addresses or user
  ids; `log.event_log` adds warnings or turns it off. `kalzit service install` registers the
  source and `uninstall` removes it.
- Stable releases can be installed and upgraded with `winget install MouseWerk.Kalzit`.
- The Windows installer has Kalzit's look: the Kalzit mark on its pages, sharp at high display
  scaling, Segoe UI, a page that shows the license (nothing to accept), and Kalzit's wording in
  English and in German with "du". Its texts stay readable in Windows contrast themes.
- The container image is signed with Sigstore cosign by the release workflow, without a key of its
  own; `cosign verify` checks that an image is the released one ("Checking the image's signature"
  in the installation guide).
- New guides for running Kalzit: backup and restore (SQLite and PostgreSQL, the secrets key, the
  ACME and plugin folders, a restore drill), upgrading per installation type, Kalzit behind nginx,
  Caddy, Traefik or IIS (with WebSocket), and the plain binary on Linux as a hardened systemd
  service. Help links in the app open the guide of the installed version instead of the newest.
- A new guide page, "Query languages for beginners", explains each source's language with small
  examples.
- The user guide is now also available in German, and the built-in help shows getting started and
  installation in German when the interface is German.

## Fixed

- Paging through a long list of dashboards, saved analyses, library panels, playlists or service
  accounts no longer repeats or skips entries on PostgreSQL.
- The first start after the update prepares the new order for every title and name. With
  hundreds of thousands of dashboards and analyses, raise "Health check after an update" on the
  Updates page before updating, so the new version is not rolled back while it does that.
- A redirect that Kalzit refuses to follow (HTTP JSON, TigerGraph) is shown as a refused request,
  as for Elasticsearch, InfluxDB and Loki, instead of as a failure of the data source.
- The debug log of the MongoDB check when saving a source no longer repeats a password that the
  server's error contains.
- An AI provider is saved only after its connection test passes; "Verbindung testen" no longer
  stores anything, and a failed test no longer overwrites a working provider.
- Behind a reverse proxy that adds to `X-Forwarded-Host` or `X-Forwarded-Proto` instead of
  replacing them, a client can no longer choose the host or scheme Kalzit believes it serves (for
  the cross-origin check, links in mails, sign-in redirects and secure cookies): only the value the
  proxy next to Kalzit set counts, and a forwarded host that is not a plain host or host:port is
  ignored. Let that proxy set both headers (nginx: `proxy_set_header X-Forwarded-Host $host;`).
- Saving a library panel or a saved analysis with a plugin panel now checks its options against
  what the plugin declares, as dashboards already did, and names the panel, the plugin and the
  option that does not fit.
- Plugin packages that would unpack to far more than their size (zip bombs) are refused by the
  `kalzit-plugin` tool as they already were by the server.
- German texts use one word for one thing: Anmerkungen, Schwellenwerte, Bibliothekspanel,
  Abfrage-Cache, Datenform and "Person" for people; the start page setting no longer reads
  "Startseite: Startseite" but offers "Start".
- Graph panels no longer lose their node labels in Windows high contrast, where the label
  background took the text color.
- Graph labels no longer cover a neighbouring node for a moment after the panel draws, the layout
  moves the nodes or the camera stops after a zoom or a pan.
- Path panels scroll instead of cutting off the last steps in a short panel.
- On a laptop screen the dashboard toolbar keeps Edit in its row: Refresh and Share show only their
  icons where the words do not fit.
- The time options of a dashboard's settings no longer show their heading twice, lie one per row
  like the other sections, and all their selects have the same height; only the open section is
  marked in the list on the left. The choice that follows each viewer's own time zone or first day
  of the week is now called "Je nach Betrachter" ("Per viewer"). Links and annotations no longer
  repeat their heading either.
- In a narrow window the breadcrumbs keep their names next to the search instead of shrinking to
  a letter, the steps of adding a data source fit on one line on a phone, a data source's
  actions line up with its cards, and the marks of the checks before an update line up.
- With the side panel of a data source open, the list no longer squeezes its columns until words
  break letter by letter; the table scrolls sideways instead. The details button and the row menu
  sit side by side in every row.
- A long step name chosen in Explore ("Vergleich mit Vorperiode") is no longer cut off; the button
  moves under it when the side panel is narrow.
- The tiles on the start page sit four in a row or two by two, never three with one left over.
- Fragen (Ask) on a phone: long data source names in the side panel and long dashboard titles in
  the "Dashboard as context" picker are shortened or wrap instead of pushing the page wider than
  the screen.
- Fragen: "Dashboard as context" puts the cursor into its search, and Escape anywhere in it or in
  "+ Source" closes the picker and returns to the button that opened it, without stopping a
  running answer. Escape on the picker's own button closes it too, and "+ Source" opens at its
  first source.
- Fragen: "AI may not read" next to a source stays on one line instead of one word per line.
- Number columns in the result tables of Ask are aligned to the right, as in other tables.
- The plugin tables (installed plugins, trusted keys, plugins of an organization) can be scrolled
  sideways with the keyboard on narrow screens, and the trusted keys no longer widen the page on a
  phone.
- In the plugin catalog on a narrow window, the "Only trusted publishers" check box keeps enough
  room from the categories above it to be tapped reliably.
- The status strip on the plugins page keeps its dividers whole however its cells wrap.
- Long plugin ids wrap after a dot instead of in the middle of a word, check boxes on the plugin
  pages look like everywhere else, and "Take back" in the trusted keys stays on one line.
- Plugins: after "Check key…" from the catalog, closing the key leads to the trusted keys
  instead of losing the focus.
- The page of a panel plugin and its messages say what turning it off does: its panels stay on
  their dashboards and show that the plugin is not available.
- Screen readers no longer announce the panel editor's options twice, and the selection and pinned
  parts of a graph node's details are no longer repeated as page regions when several graph panels
  show them.
- The contrast theme's icon shows a half-filled circle instead of stripes, and the passkey, AI,
  stat, text and library icons no longer sit off center.

## Checklist for Windows (manual)

- With Kalzit installed by the MSI, choose Help > Documentation in the top bar and open a page
  from the in-app help before signing in: both open the GitHub pages of the installed version
  (`/tree/v<version>/docs` and `/blob/v<version>/docs/guide/...`), not `main`.
- Under Datenquellen, test every source, then stop one source's database and test it again; open
  Start: "Datenquellen-Status" lists the stopped source first as "nicht erreichbar" and the others
  with their milliseconds, and "Hinweise" says the stopped source is not reachable, with "Prüfen".
- Open Explore with a MongoDB or NDJSON file source and run a query without steps, choose
  Export...: the dialog offers NDJSON and JSON only; the NDJSON file opens in Notepad with one
  document per line and umlauts intact. On a Neo4j or Memgraph source, export a graph result as
  GraphML and open it in Gephi or yEd: nodes keep their labels and properties.
- In Explore on a MongoDB source, run a query, open "Table (projection)" and choose "Project into
  a table": a step appears and the table shows the fields. Choose "Share", paste the link into
  another Edge window signed in as another editor: the same query opens and runs.
- Open Explore with a PostgreSQL or SQLite source and an empty editor: "Start here" lists the
  tables; pick one and choose "Show the first 100 rows of a table": the rows appear and the query
  stays in the editor. Press Shift+F1 inside the editor: the cheat sheet opens; search "join" and
  choose Insert.
- Run "SELECT * FROM no_such_table" in Explore: next to the error, a hint names the table and
  "Find it in the schema" moves to the schema list.
- Under Account > Preferences, set Tips to "Do not show tips", open Explore and run a query: no tip
  appears. Set it back and choose "Show all tips again".
