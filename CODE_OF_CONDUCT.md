# Code of Conduct

Kalzit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project: in issues, pull requests, reviews and any
other project space.

To report unacceptable behaviour, contact the maintainers privately through the
[MouseWerk organization](https://github.com/MouseWerk) on GitHub. Reports are handled
confidentially.
